# 🛒 ShopKart - Django E-Commerce Website

ShopKart is a full-stack e-commerce web application developed using Django. It provides a complete online shopping experience with product browsing, search, category filtering, user authentication, shopping cart management, checkout, order management, inventory control, and an admin panel.

## 🚀 Features

- User registration and login
- User logout
- Product listing
- Product details
- Product search
- Category-based filtering
- Session-based shopping cart
- Add products to cart
- Increase/decrease cart quantity
- Remove products from cart
- Stock availability management
- Checkout system
- Delivery address and contact details
- Order placement
- Order history
- Order status management
- Django admin panel
- Responsive ShopKart interface

## 🛠️ Technology Stack

- **Backend:** Python, Django
- **Frontend:** HTML5, CSS3, JavaScript
- **Database:** SQLite
- **Template Engine:** Django Templates
- **Version Control:** Git & GitHub
